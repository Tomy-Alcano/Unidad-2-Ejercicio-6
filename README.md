# Unidad-2-Ejercicio-6
Programacion 3 Unidad 2 Ejercicio 6
Ejercicio 6 — Calculadora de IMC
En este ejercicio vas a construir una pequeña aplicación funcional que combine layouts, campos de texto y eventos para procesar datos ingresados por el usuario y mostrar un resultado.

Construí una ventana que calcule el Índice de Masa Corporal (IMC) con los siguientes componentes:

Etiqueta y campo de texto para ingresar el Peso (en kilogramos)
Etiqueta y campo de texto para ingresar la Altura (en metros, por ejemplo: 1.75)
Un botón con el texto "Calcular IMC"
Una etiqueta de resultado que inicialmente muestre el texto "El resultado aparecerá aquí"
Cuando el usuario presione el botón, la aplicación debe:

Leer los valores ingresados en los campos de texto
Calcular el IMC con la fórmula: IMC = peso / (altura × altura)
Mostrar el resultado redondeado a dos decimales en la etiqueta de resultado
Recordá que los valores ingresados en un JTextField son siempre de tipo String. Necesitás convertirlos a double antes de operar con ellos.

💡 Tip: para convertir un String a double usá Double.parseDouble(texto). Para redondear el resultado a dos decimales, investigá String.format("%.2f", valor).
